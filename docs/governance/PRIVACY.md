# Privacy Principles

## Local by default

Perfis, histórico, progresso, favoritos, listas e recommendation signals são locais. Nenhuma conta é exigida.

## Data minimization

Não enviar histórico/gostos a providers salvo dado estritamente necessário à ação solicitada. Não adicionar telemetry/analytics remotos sem decisão explícita, documentação e opt-in apropriado.

## Backup

Manual file backup é primary portability. Futuro Drive/Turso é opcional e deve documentar exatamente o que sai do dispositivo.

## Perfil infantil

Dados permanecem locais no v1. Qualquer future cloud envolvendo crianças exige revisão legal/privacidade específica antes de habilitar.

## User control

Usuário deve poder exportar, restaurar e apagar seus dados locais. Cache pode ser limpo separadamente sem apagar biblioteca pessoal.
