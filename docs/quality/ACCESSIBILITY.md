# Accessibility

Meta: WCAG 2.2 AA onde aplicável à UI desktop/web.

- Navegação completa por teclado e controle/foco previsível.
- Focus ring visível e sem keyboard trap.
- Contraste mínimo adequado para texto e controles.
- Nomes acessíveis para IconButtons Lucide.
- Headings/landmarks semânticos.
- Dialogs capturam/restauram foco corretamente.
- `prefers-reduced-motion` respeitado.
- Posters têm alt contextual; imagens decorativas são ignoradas.
- Progresso não depende somente de cor.
- Zoom/font scaling não quebra fluxos principais.

Acessibilidade é gate de UI, não revisão exclusivamente no fim.
