# ADR-0003 — Wails v3 no desktop

- Status: **Accepted**
- Date: 2026-08-15

## Decision

Usar Wails v3 como shell/transport desktop, com Go e Svelte.

## Rationale

Objetivo de baixo consumo e caminho mobile futuro.

## Consequences

Exige pin de versão e validação do beta/API durante desenvolvimento.
