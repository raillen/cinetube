# ADR-0006 — Desktop v1 antes de Web/Android

- Status: **Accepted**
- Date: 2026-08-15

## Decision

Completar desktop local-first antes de PWA/Android/cloud.

## Rationale

Controla escopo e cria domínio/contratos testados antes da expansão.

## Consequences

Arquitetura deve preservar portas para futuros adapters sem implementá-los antecipadamente.
