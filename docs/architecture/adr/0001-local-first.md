# ADR-0001 — Local-first como fonte de verdade

- Status: **Accepted**
- Date: 2026-08-15

## Decision

Perfis, histórico, progresso, listas e preferências são locais. Cloud é opcional.

## Rationale

Reduz dependência operacional, melhora privacidade/offline e mantém o produto utilizável sem conta.

## Consequences

Backup/import e sync precisam ser projetados como adapters.
