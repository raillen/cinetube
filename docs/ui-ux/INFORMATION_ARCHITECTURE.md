# Information Architecture

## Navegação principal

- Home
- Explorar
- Biblioteca
- Pesquisa (ícone/atalho)
- Perfil/Settings

## Biblioteca

Favoritos, Assistir mais tarde, Continuar assistindo, Histórico, Minhas listas e Ocultos.

## Explorar

Filmes, Séries, Animes/Doramas conforme provider/metadata; filtros avançados ficam disponíveis sem lotar a Home.

## Details

A URL/route interna identifica `MediaID`. A tela reúne metadata e ações locais; playback é ação separada.

## Princípio

A Home responde “o que devo continuar/ver agora?”. Explorar responde “o que existe?”. Search responde “encontre exatamente isto”. Biblioteca responde “o que eu salvei/fiz”.
