# CineTube — Guia do Produto (planejado para v1)

> Este guia descreve o comportamento alvo. Enquanto `PROJECT_STATE.md` indicar pre-implementation, não implica que a funcionalidade já exista.

## Perfis

Cada pessoa pode ter seu próprio perfil local com histórico, progresso, listas e recomendações. Não é necessário cadastro online.

## Home

Mostra poucos blocos relevantes: continuar assistindo, recentes e recomendações locais. Para navegar no catálogo completo, use Explorar/Pesquisa.

## Biblioteca

Favoritos, Assistir mais tarde, Histórico, Continuar e listas personalizadas.

## Backup

Exporte regularmente um arquivo de backup portátil em Settings. Backup pode ser protegido por senha; cache de imagens não precisa ser levado.

## Providers

Conteúdo e metadata dependem de serviços externos. Se um provider falhar, seus dados pessoais locais permanecem no dispositivo.
